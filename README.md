# Ana Orthodox — أنا أرثوذكس

**A comprehensive Coptic Orthodox digital platform.**

---

## Project Overview

Ana Orthodox is an installable Progressive Web Application providing unified access to Coptic Orthodox spiritual, educational, biblical, liturgical, and community resources — delivered in an Arabic-first, RTL-first experience.

## Technology Stack

| Layer             | Technology                         |
| ----------------- | ---------------------------------- |
| Frontend          | Next.js 15 App Router + TypeScript |
| Backend           | NestJS + Node.js LTS               |
| Database          | PostgreSQL 16 + Prisma ORM         |
| Design System     | Material 3 (Custom Coptic Theme)   |
| Application Model | Progressive Web App (PWA)          |
| Primary Language  | Arabic (RTL)                       |
