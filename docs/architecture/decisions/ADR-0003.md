# ADR-0003: Arabic RTL as Primary Direction and Typography Architecture

**Status:** ACCEPTED  
**Date:** 2026-11-17  
**Deciders:** Principal Software Architect, Design System Agent, Frontend Agent

---

## 1. Context and Problem Statement

Ana Orthodox is targeted at the Arabic-speaking Coptic Orthodox community worldwide. A secondary requirement is the accurate rendering of liturgical Coptic script and future English translations. The entire interface, user interaction patterns, gestures, navigation flows, and layout systems must be conceived RTL-first, rather than retrofitting an LTR layout.

## 2. Considered Options

1. **LTR-Default with CSS Mirroring / Flipped Properties:** Authoring in LTR and applying automatic transform/mirror plugins.
2. **Native RTL-First Architecture:** Setting `<html dir="rtl" lang="ar">`, using CSS logical properties (`start`, `end`, `margin-inline`, `padding-inline`), Material 3 RTL layout specifications, and dedicated Arabic/Coptic web fonts.

## 3. Decision Outcome

Chosen Option: **Option 2 — Native RTL-First Architecture**.

### Key Specifications:

- **Root Element:** `<html dir="rtl" lang="ar">`.
- **CSS Engine:** Tailwind CSS with logical properties (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`) instead of directional `left`/`right`.
- **Primary Arabic Font:** `Noto Naskh Arabic` (via `next/font/google`), selected for its formal, ecclesiastical, highly legible calligraphic structure suitable for liturgical and biblical texts.
- **Coptic Script Font:** `Noto Sans Coptic` loaded as a fallback font family for Coptic hymn lyrics and inscriptions.
- **Directional Mirroring:** Navigation drawers slide from the right; back arrows point right (`arrow_forward` in LTR is back in RTL); reading progress indicators flow right-to-left.

## 4. Consequences

- **Positive:** Authentic, ergonomic native user experience for Arabic readers; zero layout glitches caused by post-render flipping.
- **Negative:** Third-party UI components must be rigorously audited for bidirectional/RTL compliance before adoption.
